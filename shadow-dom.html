Shadow DOM Testing Fixture

Comprehensive test surface for Shadow DOM element discovery, spatial filtering, nested contexts, and mixed iframe/shadow scenarios.

Section 1 — Basic Shadow DOM (Open Roots)

Single Shadow Host with Various Element Types

Each element type (button, textbox, checkbox, link, select) is represented inside an open shadow root. Used to verify basic discovery.

Section 2 — Multiple Shadow Hosts

Independent Shadow Hosts with Overlapping Content

Two shadow hosts containing buttons with identical text. Spatial filters (above, below, within) are required to disambiguate.

Section 3 — Nested Shadow DOM

Two-Level Nested Shadow Roots

Outer shadow host contains an inner shadow host. Target element is inside the innermost shadow root.

Three-Level Deep Nested Shadow Roots

Triple nesting to test recursive scanning depth and coordinate chaining.

Section 4 — Spatial Filtering

Shadow Elements with Spatial Relationships

Layout designed to test spatial filters (above, below, within, near, toLeftOf, toRightOf) against shadow DOM elements.

Section 5 — Shadow DOM Inside iFrame

Shadow Host Within an iFrame Document

Tests the combination of frame switching and shadow root penetration. The shadow host lives inside the iframe's document.

Section 6 — Closed Shadow Roots

Closed Shadow Root (Inaccessible)

Closed shadow roots should not be queried. Tests verify graceful handling and appropriate error behavior.
